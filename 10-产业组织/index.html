产业组织

Industrial Organization

微观经济学告诉我们完全竞争与垄断的极端世界，但真实市场几乎都活在这两者之间：几家航司、两大外卖平台、一个微信。产业组织（IO）研究真实市场如何运转、企业如何竞争与合谋、什么时候需要政府出手——它是微观理论落地为反垄断政策的那座桥。

学完本分支你将能
  • 用勒纳指数与 HHI 度量市场势力，并说明两者的信息基础与局限
  • 在古诺与伯特兰框架下预测寡头价格，解释厂商数增加时价格如何趋近竞争水平
  • 用重复博弈的贴现因子逻辑解释卡特尔为何不稳定、默契合谋何时可以维持
  • 应用三级价格歧视的反向弹性法则，并区分合法差别定价与"大数据杀熟"
  • 分析进入壁垒与掠夺性定价等策略性行为，理解反垄断的消费者福利标准
  • 用网络效应、临界质量、双边市场解释平台竞争与"免费"商业模式

第 1 章市场势力：谁能定价，谁只能接受价格

引入问题：同样一瓶水，便利店卖 2 元、山顶景区卖 10 元；茅台可以年年提价，面粉厂却只能随行就市。差别不在于成本——在于谁有定价权。产业组织的第一个任务，就是给"市场势力"（Market Power）装上刻度尺：它有多大？从哪里来？

核心直觉：市场势力 = 定高价而不丢光顾客的能力

完全竞争厂商涨价一分钱，顾客全部跑光——它是"价格接受者"。有市场势力的厂商涨价，只会丢掉一部分对价格敏感的顾客，因为它卖的东西缺少相近替代品。势力的来源五花八门：独特产品、专利、牌照、规模经济、网络效应、转换成本……但测量只有两条路：一是看行为——价格比边际成本高出多少（勒纳指数）；二是看结构——市场集中到什么程度（HHI）。前者直观但边际成本难以观察，后者只需份额数据但只是势力的"代理指标"。

关键概念

市场势力 Market Power
将价格定在边际成本之上而不失去全部顾客的能力。来源于替代品稀缺；是利润与政策分析的共同起点。
勒纳指数 Lerner Index
L = (P − MC)/P，取值 0（完全竞争）到 1（极端）。利润最大化下恰好等于 1/|ε|：需求越缺乏弹性，势力越大。
赫芬达尔-赫希曼指数 Herfindahl-Hirschman Index, HHI
所有厂商市场份额（百分数）的平方和，范围 0–10000。对大厂商更敏感：一家独占即 10000，无限多小厂商趋近 0。
加成率 Markup
价格相对边际成本的加成幅度，常写作 P/MC 或 (P − MC)/P。经验研究中"加成上升"是市场势力扩张的同义语。
HHI = s₁² + s₂² + … + sₙ²sᵢ 为第 i 家厂商的市场份额（百分数）。四家各 25% → HHI = 2500；独家独占 100% → 10000。
L = (P − MC) / P = 1 / |ε|利润最大化的加成法则：弹性 |ε| 越小（顾客越跑不掉），最优加成越高。完全竞争时 |ε|→∞，L→0。

现实世界 · 可口可乐收购汇源为何被否

2008 年可口可乐拟以约 24 亿美元收购汇源果汁。2009 年 3 月，商务部依据刚施行半年的《反垄断法》禁止该项经营者集中——理由正是集中度逻辑：并购将使可口可乐在果汁类市场的份额显著上升，"集中度的增加将产生排除、限制竞争效果"，且对上游果农的买方势力同样有碍竞争。这是中国《反垄断法》实施后第一个被禁止的并购案，也是 HHI 式分析（份额 + 边际变化）进入中国监管实践的标志性事件。

常见误区

"市场份额高 = 违法垄断。"——反垄断处罚的是滥用势力的行为，而非势力本身；高份额可能只是产品更好的回报。反向误区同样常见："HHI 高 = 一定有高利润。"——若进入壁垒低，高集中度市场的利润会被潜在进入瞬间侵蚀（见第 5 章"可竞争市场"）。此外 HHI 完全取决于相关市场如何界定：把市场定义得越宽（"饮料"vs"100% 果汁"），HHI 就越低——"市场界定"往往是反垄断诉讼真正的第一战场。

自测 1.1某市场四家厂商份额为 30%、30%、20%、20%。HHI 及集中度档位为？
解析：HHI = 30²+30²+20²+20² = 2600。A 混淆了集中率（CR4，四家之和=100%）与 HHI（平方和）；平方让大厂商权重更高，因此 HHI 对"一家独大"远比对"群雄均分"敏感。C 计算正确但档位记错：2600 > 2500，按美国合并指南口径属高度集中。顺带一算：四家均分 25% 时 HHI 只有 2500，恰好压线。
自测 1.2某厂商利润最大化售价对应的需求弹性 |ε| = 5。其勒纳指数为？
解析：利润最大化的一阶条件 MR = MC 展开即 (P − MC)/P = 1/|ε| = 1/5 = 0.2。A 把弹性与势力的关系弄反了：顾客越跑不掉（|ε| 越小），加成才越高；|ε|→∞ 时 L→0，正是完全竞争。B 是把 1/5 误算为 0.5。经验研究中经济学家常反过来用这把尺子：测出加成，反推弹性与势力。

本章小结

  • 市场势力 = 定价高于边际成本而不流失全部顾客的能力，根源是替代品稀缺
  • 勒纳指数 L = (P − MC)/P = 1/|ε|，从行为侧测量势力；缺点是边际成本难以观察
  • HHI = 份额平方和（0–10000），从结构侧测量集中度；对大厂商权重更高
  • 两条路都只是代理指标：HHI 忽略进入壁垒，L 难以核算——反垄断需要二者互证
  • 相关市场界定先于一切计算：市场划宽划窄，HHI 天差地别

第 2 章寡头竞争：古诺与伯特兰

引入问题：只有两三家厂商的市场，价格一定高吗？民航、水泥常年维持远高于成本的价格；可网约车、外卖的补贴大战却把价格杀到成本线以下。同样是寡头，为什么结局天差地别？答案是：竞争的变量不同——厂商抢的是"产量"还是"价格"。

核心直觉：选数量像"分蛋糕"，选价格像"抢蛋糕"

古诺竞争（Cournot）：各厂同时决定产量，价格由市场出清决定。你多产一单位，会压低所有人面对的价格——每家都只考虑自己对价格的影响，产量自然低于竞争但高于垄断。厂商越多，"自己对价格的影响力"越被稀释，均衡价格一路滑向边际成本。伯特兰竞争（Bertrand）：各厂同时标价，顾客全部涌向最便宜的一家。只要你的价格比对手高一分钱，你就颗粒无收——于是互相削价，直到价格 = 边际成本，哪怕只有两家。这就是"伯特兰悖论"：两家足以复现完全竞争。现实介于两者之间：产能约束让"价格战"打不完全（接近古诺），产品差异让低价者拿不走全部顾客（弱化悖论）。

关键概念

古诺竞争 Cournot Competition
厂商同时选择产量、市场出清定价的寡头模型。n 家同质厂商的均衡价格介于垄断价与边际成本之间，且随 n 增大单调下降。
伯特兰竞争 Bertrand Competition
厂商同时标价、消费者只买最低价的模型。同质品 + 相同边际成本时，两家即可把价格压到边际成本。
伯特兰悖论 Bertrand Paradox
"只需两个对手就能得到竞争结果"的反直觉结论。靠产能约束、产品差异、重复互动三个现实因素化解。
反应函数 Reaction Function / Best Response
给定对手产量（或价格），自己的最优选择。纳什均衡即两条反应曲线的交点——"我对你的最优应对，恰是你的最优应对"。
模型决策变量同质品、两家厂商的均衡价格直觉
垄断产量或价格P = (a + c)/2独占全市场需求
古诺（n 家）产量P = (a + n·c)/(n + 1)各自忽视压价的外溢，产量偏高
伯特兰价格P = c（边际成本）低价者通吃，削价到成本线
P* = (a + n·c) / (n + 1)　→　n = 1 时为垄断价，n → ∞ 时 P* → c线性需求 P = a − bQ、常数边际成本 c 下的对称古诺均衡。厂商数 n 是"竞争强度"的旋钮。

现实世界 · 网约车补贴战：一场伯特兰实验

2014 年前后，滴滴、快的与后来的优步中国为争夺同质的出行服务，展开教科书级的伯特兰价格战：每单补贴、双向红包、周末免单——价格长期低于成本，三年累计"烧钱"以百亿计。同质品 + 零转换成本，顾客自然全流向补贴多的一家，任何一方都不敢先停。这场实验的结局同样经典：价格战无法盈利，2016 年滴滴与优步中国合并，补贴退坡，价格回归（偏古诺式的）常态。价格战的起点是伯特兰逻辑，终点往往是集中度上升——这正是第 5 章反垄断关注的"掠夺式补贴"争议。

常见误区

"只有两三家厂商，必然勾结卖高价。"——伯特兰告诉我们：只要产品同质、无产能约束、一次性较量，两家就能把价格打到成本线。"价格战对消费者永远是大好事。"——短期是真，但若价格战的目的在于把对手打出市场、为日后提价铺路（掠夺性定价），长期未必。另一个技术误区：把古诺与伯特兰当成"对的 vs 错的"模型——它们是同一市场的两种极端制度，现实的产能投资（先定产能≈古诺）与菜单标价（先标价≈伯特兰）分别接近两者。

自测 2.1两家厂商生产完全同质的产品，边际成本同为 10 元，一次性同时定价，低价者获得全部市场（并列则平分）。纳什均衡价格是？
解析：P = 10 时谁也没有偏离动机：提价丢失全部顾客，降价则低于成本卖得越多亏得越多。A 错在低于成本无利可图；C 描述的是合谋，需要重复博弈的条件支撑（第 3 章），一次性博弈中"偷偷降价"是占优策略——这正是伯特兰悖论：两家足以复现完全竞争。
自测 2.2在对称古诺模型中，厂商数 n 从 2 增加到 10，均衡价格将？
解析：P* = (a + n·c)/(n+1) 对 n 单调递减：n=1 是垄断价，n→∞ 时 P*→c。n=2 时 P≈46.7，n=10 时 P≈27.3（a=100、c=20）。古诺模型因此给出从垄断到竞争的连续谱——"原子式竞争"不是质变而是极限。A 把合谋直觉（第 3 章）套在了不合作模型上；C 忽略了策略互动的结构。

本章小结

  • 寡头结果取决于竞争变量：古诺选产量（价格介于垄断与竞争之间），伯特兰选价格（直接打到成本线）
  • 伯特兰悖论：同质品 + 相同成本 + 一次性博弈，两家厂商即得 P = MC
  • 化解悖论的三个现实因素：产能约束、产品差异、重复互动
  • 古诺价格随厂商数单调下降趋向边际成本：n 是竞争强度的旋钮
  • 价格战（网约车案例）起点是伯特兰逻辑，终点常是集中度上升

第 3 章合谋与卡特尔：为什么背叛是常态

引入问题：OPEC 开一次会，全球油价应声而动——合谋的力量毋庸置疑。可历史数据又显示：卡特尔成员几乎总是偷偷超产，组织一次次名存实亡。既然合谋利润那么高，为什么"坐在一张桌子上的人"总是貌合神离？

核心直觉：合谋是场需要"未来"来维系的囚徒困境

把古诺双寡头换成"联合垄断"：两家各产垄断产量的一半，分得的利润都比古诺均衡高——合谋有利可图。但给定对方守约，你偷偷多产的那一部分按高价卖出，利润更高：背叛是占优策略。一次性博弈里，卡特尔必然瓦解，这就是卡特尔的内在不稳定性。唯一的解药是重复博弈：如果今天背叛、明天就遭到报复（大家回到古诺低价的"惩罚期"），而明天足够重要（贴现因子 δ 足够大），背叛的眼前便宜抵不过未来的损失，合作就能靠"未来的阴影"自我维持——甚至无需一纸协议，这叫默契合谋（Tacit Collusion）。

关键概念

卡特尔 Cartel
以限制产量、抬高价格为目标的显式厂商联盟。多数法域属本身违法；国家间卡特尔（OPEC）不受任何反垄断法管辖。
默契合谋 Tacit Collusion
无协议、靠相互理解的协调涨价。法律上极难认定与打击——反垄断的前沿难题。
触发策略 Grim Trigger
重复博弈中的惩罚机制：只要没人偏离就一直合作；一旦有人偏离，永久回归低利润的惩罚均衡（如古诺）。
贴现因子 Discount Factor δ
明天的 1 元钱在今天的价值（0–1）。δ 越大说明未来越重要、参与者越有耐心，合谋越容易维持。
δ ≥ (π背 − π合) / (π背 − π纳)合谋可维持的条件：π合 = 守约利润，π背 = 一次性背叛利润，π纳 = 惩罚期（如古诺）利润，δ = 贴现因子。背叛诱惑越大，需要的耐心越大。
现实世界 · OPEC 与两场价格战

2014 年 11 月，OPEC 拒绝减产保价，任由油价从约 100 美元跌至 2016 年初的 30 美元下方——市场普遍解读为对北美页岩油的惩罚性增产：用低价把高成本产能挤出市场，正是"触发策略"的国家队版本。2020 年 3 月，减产谈判破裂后沙特大幅调降官方售价、宣布增产，油价单日暴跌，史称"沙俄价格战"。与此同时，跨国卡特尔一旦进入司法视野则代价惨重：20 世纪 90 年代的国际维生素卡特尔（罗氏、巴斯夫等）在欧美被处以数十亿美元罚款，多位高管入狱——显式卡特尔赚的是垄断利润，赌的是刑期与罚金。

常见误区

"合谋必须签协议、开密室会议。"——重复博弈可以让"心照不宣"成为均衡：跟随式调价、最惠国条款、公开宣布未来产量，都可能扮演协调装置，这让默契合谋成为执法难题。"价格上涨就是有卡特尔。"——成本冲击（原油、芯片短缺）同样推价；判断合谋要找的是"成本没变而价格齐步走"、丰水期限产之类的行为证据，而非只看价格。反过来，"卡特尔一旦成立就稳赚"也错：内部背叛动机 + 外部新进入 + 需求波动，三股力量随时撕扯它。

自测 3.1以下哪种市场环境下，默契合谋最难维持？
解析：触发策略的前提是观测：能把"生意变少"归因于背叛才谈得上惩罚。B 中噪音掩盖了背叛信号，惩罚机制失灵，合谋最易瓦解——这正是"繁荣时期价格战更频"的理论解释。A、C 都是合谋的稳定剂：对手少、透明、δ 高，公式 δ ≥ (π背−π合)/(π背−π纳) 更容易满足。
自测 3.2卡特尔"内在不稳定"的经济学根源是？
解析：在卡特尔内部，P > MC 意味着多卖一单位几乎是纯利：π背 > π合 > π纳的囚徒困境结构才是命门——即便没有执法，OPEC 也屡屡超产。A 是小数目摩擦；C 是外在约束且对国家间卡特尔（OPEC）根本不适用，谈不上"内在"不稳定。加上外部进入者蚕食超额利润，卡特尔内忧外患。

本章小结

  • 合谋利润高于古诺均衡，但一次性博弈中背叛是占优策略——卡特尔是放大版囚徒困境
  • 重复博弈 + 触发策略可以维持合作，条件：δ ≥ (π背−π合)/(π背−π纳)
  • 合谋的稳定剂：厂商少、行为透明、需求平稳、δ 高；干扰项：噪音、秘密折扣、新进入
  • 默契合谋无需协议，法律认定极难，是反垄断的前沿难题
  • OPEC 案例显示：增产惩罚可对外（挤走页岩油），成员超产则自内瓦解卡特尔

第 4 章价格歧视：为同一瓶水付不同的钱

引入问题：同一航班、相邻座位、同一餐食，票价可能相差一倍；软件分"家庭版/专业版"，后者贵五倍却只多了些你用不到的功能；电影院的学生票几乎是成人价的对折。企业凭什么、又如何做到"看人下菜碟"？这对消费者是好事还是坏事？

核心直觉：统一价格把消费者的钱"留在桌上"

统一定价时，支付意愿 500 元的顾客只付 300 元——200 元消费者剩余留在了桌上。厂商的梦想是按每个人的支付意愿逐个收价：一级价格歧视（完全歧视）把剩余全部收走，产量却达到有效水平；信息有限时退而求其次——二级靠"菜单自选"（数量折扣、版本划分）让顾客自己亮底牌；三级按可观察的群体特征（学生、老人、地区）分组定价。三级歧视的定价法则极其简洁：弹性低的群体定高价，弹性高的群体定低价——商务客赶时间别无选择（弹性低）付全价，学生时间充裕四处比价（弹性高）买折扣票。

关键概念

价格歧视 Price Discrimination
对同一商品向不同顾客收取不同价格（且差异并非源于成本差异）。前提：市场势力 + 能区分支付意愿 + 能阻止转售。
支付意愿 Willingness to Pay, WTP
顾客愿为一件商品付出的最高金额。歧视的全部艺术就是让价格逼近每个人的 WTP。
版本划分 Versioning
二级歧视的自选菜单：刻意制造"高级版/阉割版"（软件、航班舱位），让高 WTP 顾客自费选择高价版本。
个性化定价 Personalized Pricing
依托用户画像按人报价，俗称"大数据杀熟"。信息时代的近似一级歧视，也是监管焦点。
类型区分依据典型例子福利性质
一级（完全）逐人 WTP一对一议价、大数据杀熟（近似）产量有效，剩余全归厂商
二级（自选）消费数量/版本数量折扣、舱位、软件版本不确定，常扩大覆盖面
三级（分群）可观察群体学生票、老年人优惠、区域定价不明确：可能服务到原本没人服务的小市场
(Pᵢ − MC) / Pᵢ = 1 / |εᵢ|三级歧视的反向弹性法则：各分市场独立套用勒纳加成公式——弹性 |εᵢ| 越小（顾客越不敏感），该市场价格越高。

互动演示：两市场对比

现实世界 · 从收益管理到"大数据杀熟"监管

民航业是价格歧视的教科书：同一航班按购票时间、退改条件、渠道切出几十个票价桶，"收益管理"系统实时求解本图的加成公式——深夜出发、提前两月购票的休闲客（弹性高）拿到低价，临时必须出行的商务客（弹性低）付全价。数字时代把分组做得更狠：同一平台、同一商品，老用户看到更高价格——"大数据杀熟"。中国 2021 年施行的《个人信息保护法》第 24 条明确禁止"在交易价格等交易条件上实行不合理的差别待遇"，此前深圳等地已先行立法；监管的关键词恰是"不合理"：基于成本的差别定价（快递到偏远地区更贵）合法，基于"你懒得比价"的算法定价被禁。

常见误区

"价格歧视总是让消费者更糟。"——未必：三级歧视可能把统一高价下"没人服务"的小市场（学生、小语区）纳入供给，一级歧视下总产量等于竞争水平、无谓损失为零（只是剩余换了口袋）。判断福利要看产量效应而非直觉义愤。反向误区："凡是差别价格都算歧视。"——反映成本差异的定价（高峰电价、远途运费）不是歧视；真正的歧视要求价差不来自成本差。还有执行前提常被忽略：若能轻易转售，学生票会被倒卖到套利消失——所以歧视集中在服务与体验（须本人乘机）而非可转售的实物。

自测 4.1电影院对学生半价、对成人全价。依据反向弹性法则，其定价逻辑是？
解析：(P − MC)/P = 1/|ε| 对每个分市场分别成立：|ε学生| 大 → 最优加成低 → 低价；|ε成人| 小 → 高价。这不是慈善（A），也不是成本差异（C——同一场电影的座位成本人人相同），而是把"对价格敏感的人"筛出来低价供给、同时保住"不敏感者"的高价。前提是学生证可验证、票不可转售。
自测 4.2在一级（完全）价格歧视下，市场的产量与剩余分配是？
解析：每单按买者 WTP 收价，只要 WTP ≥ MC 就成交——所有互利交易都发生，产量恰好是需求曲线与 MC 的交点，无谓损失消失；但每单的价格都擦着 WTP，消费者剩余被榨干，全部落入厂商。这是"效率与分配必须分开评价"的极好例子：一级歧视有效率上的"优点"与分配上的"难看"。A 描述的是普通垄断；C 无中生有——高于 WTP 的交易不会发生。

本章小结

  • 价格歧视三前提：市场势力 + 可区分 WTP + 可阻断转售
  • 一级逐人定价（剩余全归厂商、产量有效）；二级靠菜单自选（版本划分）；三级按群体分市场
  • 三级歧视核心公式：(Pᵢ − MC)/Pᵢ = 1/|εᵢ|——弹性小者付高价
  • 福利评价看产量效应：歧视可能扩大服务范围，也可能只是转移剩余
  • 监管划线在"合理性"：成本性差异定价合法，算法杀熟被《个人信息保护法》禁止

第 5 章进入壁垒与反垄断

引入问题：网约车平台曾以巨额补贴"先亏两年、再赚十年"——把对手烧死再提价，这在经济学上说得通吗？法律上又为什么极难定罪？更根本的问题：当一家企业占据大半市场，监管者该惩罚它的"大"，还是只管它对竞争的"坏"？

核心直觉：垄断利润是块磁铁，壁垒是围栏

超额利润会像血腥味一样引来鲨鱼——新厂商闻风而入，产量扩大、价格回落。因此真正决定市场势力能否持续的，不是今天的份额，而是进入壁垒的高低。壁垒有的天生（结构性）：规模经济摊薄固定成本、专利保护、网络效应自我强化、用户转换成本；有的是故意的（策略性）：限制定价（压低价格让进入无利可图）、过剩产能威胁、捆绑排他、掠夺性定价（先亏本把对手赶走、垄断后加倍赚回）。反垄断的全部艺术，就是在"保护竞争"与"惩罚成功"之间走钢丝——现代主流采用消费者福利标准：看行为是否抬高了价格、减少了产量、抑制了创新，而非简单看企业大小。

关键概念

进入壁垒 Entry Barriers
使在位者能持续把价格提至成本之上而新厂商仍不进入的因素。结构性：规模经济、专利、网络效应、转换成本；策略性：限制定价、排他协议。
沉没成本 Sunk Cost
进入后无法收回的支出（专用设备、品牌广告）。沉没成分越高，进入越谨慎——在位者可借此威慑。
掠夺性定价 Predatory Pricing
以低于成本的定价驱逐对手、再靠垄断定价收回损失的策略。理论上可行，法律上须证明"低于成本 + 事后补偿的可靠前景"。
可竞争市场 Contestable Market
进入退出无沉没成本时，哪怕一家独占也不敢定高价——潜在竞争替代实际竞争。敲打"只看集中度"的静态思维。
现实世界 · "二选一"与平台反垄断风暴

2021 年 4 月，国家市场监管总局认定阿里巴巴滥用市场支配地位，禁止平台内商家"二选一"（不得同时在竞争平台开店），罚款 182.28 亿元；同年 10 月，美团因同类行为被罚 34.42 亿元。处罚的靶心不是"平台大"，而是排他行为：二选一既抬高了商家的经营成本，也削弱了其他平台获取供给的能力——典型的策略性壁垒，伤害的是竞争过程本身。同期整治还包括禁止大数据杀熟、屏蔽外链等。这一系列案件标志着中国平台经济监管从"包容审慎"转向"常态化监管"，分析框架则与国际接轨：界定相关市场 → 认定支配地位 → 审查行为是否排除、限制竞争。

常见误区

"企业大了就该拆。"——反垄断保护的是竞争，不是竞争者，更不是"惩罚优秀"：高份额若源于更低成本与更好产品，拆分只会伤害消费者。"降价永远是好事。"——低价若属于掠夺性定价（低于成本 + 日后补偿），短期便宜是长期垄断的诱饵；但也别走向另一极端——看到低价就喊掠夺：法律要求证明价格低于恰当的成本基准、且掠夺者有能力回收"投资"，绝大多数降价只是效率。"亏损补贴 = 掠夺。"——还需要"补偿可能"这一环：若市场可自由进入，提价之日就是新对手进门之时，掠夺无从回本。

自测 5.1法律上把掠夺性定价与合法降价区分开来，最关键的证据组合是？
解析："低于成本"证明这是投资而非竞争（没人亏本卖是为乐趣）；"补偿前景"证明这是策略而非自杀（阿瑞达-特纳成本检验 + 事后回收分析）。缺一不可：只看低价会把效率竞争误判为掠夺，只看对手受伤会沦为保护竞争者而非竞争。A、C 都是情绪证据，不构成经济逻辑。
自测 5.2决定一家厂商的市场势力能否长期持续的最关键因素是？
解析：垄断利润是最醒目的广告：只要进入自由，超额利润必然被新产能侵蚀——可竞争市场理论甚至证明，进入威胁本身就足以压低价格。因此反垄断审查先问"对手能不能进来"（壁垒、沉没成本、排他协议），再看份额。A 忽略了份额可能是效率的结果且随时可被侵蚀；C 是最朴素的归纳谬误。

本章小结

  • 垄断利润吸引进入：进入壁垒（结构性 + 策略性）决定势力能否持续
  • 沉没成本越高，进入越慎重——在位者可借此威慑（限制定价、过剩产能、排他协议）
  • 掠夺性定价认定 = 低于成本 + 补偿前景，二者缺一即沦为误判
  • 现代反垄断主流采用消费者福利标准：保护竞争，而非保护竞争者、更非惩罚规模
  • "二选一"案：打击的是排他行为这一策略性壁垒，不是平台规模本身

第 6 章网络效应与平台经济

引入问题：哪怕明天出现一款功能强一倍的聊天软件，你大概率也不会换——因为你的朋友都在微信上。为什么有的市场"赢家通吃"，而有的市场巨头林立？为什么平台对用户永远免费、对商家重抽佣金，甚至倒贴钱请用户上车？

核心直觉：用户本身成为产品价值的一部分

一般商品的价值来自生产端；网络产品的价值却来自其他用户——用微信的人越多，微信对你越有用。这叫需求侧规模经济（网络效应），它带来三个后果：第一，临界质量——用户基数不够时没人想加入（负反馈死亡螺旋），跨过临界点后增长自我强化（正反馈）；第二，赢家通吃倾向——领先者吸走用户，落后者加速失血；第三，锁定——转换成本随社交图谱、数据、习惯累积。平台做的是双边市场生意：乘客越多司机越想加入，司机越多打车越快——两侧互相吸引。于是定价可以"非中性"：对弹性大、网络贡献高的一侧免费甚至补贴（用户），向弹性小、依赖性强的一侧收费（商家、司机）。免费不是慈善，用户侧本身就是"进货"。

关键概念

网络效应 Network Effects
用户从产品中获得的效用随用户总数增加而上升。直接效应（社交网络）与交叉效应（平台两侧互吸，如买家与卖家）。
双边市场 Two-sided Market
平台连接两类用户群，一侧的规模影响另一侧的价值。最优定价看总的双边利润，因此常见"一侧补贴、一侧收费"。
临界质量 Critical Mass
使加入的净收益由负转正的用户基数。低于它网络萎缩，高于它增长自驱动——冷启动难题的解就是先烧钱买临界质量。
赢家通吃 Winner-take-all
强网络效应 + 低多归属 + 无差异化空间时的极端结果：市场由一家独占。多归属（同时装两个 App）与技术代际更替会削弱它。

互动演示：临界质量

现实世界 · 红包大战：用钱买"临界质量"

2014 年春节，微信凭"抢红包"一夜之间完成数百万用户的银行卡绑定——被马云称为"珍珠港偷袭"。支付宝的反击同样直白：2016 年春晚联手央视首推"集五福"，集齐者平分超 2 亿元红包，此后"集五福"年年拉新。表面是营销战，本质是临界质量公式的应用：支付是典型的双边网络（付款方 ↔ 收款方），补贴（现金红包）等于临时抬高 v、把净收益线推过零点，让用户基数越过 n*；此后线下扫码场景的正反馈接棒。今天两大平台对个人转账免费、对商户收款抽成，正是"补贴弹性大的一侧、向依赖强的一侧收费"的双边定价。

常见误区

"免费 = 没赚钱 = 没有市场势力。"——零价格不等于零价格势力：当用户以注意力、数据、社交关系"付款"，免费侧恰恰是平台的进货渠道；对免费侧的排他行为（屏蔽外链、限制分享）同样可能损害竞争。"网络效应必然赢家通吃。"——只有当网络效应强、用户难以多归属（同时用多个平台）、产品同质时才成立；反之，Instagram 与 TikTok 并存、滴滴与高德打车同框——多归属、细分场景与代际技术（从文字到短视频）都能维持多强格局。分析平台市场，先画清楚"哪几边、谁补贴谁"。

自测 6.1网约车平台对新乘客发大额补贴、向司机抽成。双边市场理论的解释是？
解析：双边定价看总利润而非单边：乘客多 → 打车快 → 司机更愿入驻 → 车多 → 乘客更多（交叉网络效应）。对价格敏感、网络贡献大的一侧收低价甚至补贴，能撬动整个循环（罗歇-梯若尔的"非中性"结果）。A 把策略当慈善；C 方向反了——抽成恰恰以司机端的依赖性（低弹性）为前提，而非以减少司机为目标。
自测 6.2某社交产品当前用户基数低于临界质量，市场反馈将把它推向？
解析：低于临界质量时 U(n) < 0：加入即亏、留下也亏，负反馈主导——这正是绝大多数社交产品死在"冷启动"的原因，也是烧钱补贴（临时抬高 v）的唯一理性：把基数推过 n*，让正反馈接棒。A 把"越过临界点之后"的逻辑错安到之前；C 的稳态不存在：两侧都是流失的漏斗，不进则退。

本章小结

  • 网络效应 = 需求侧规模经济：用户越多产品越好用，价值由用户共同生产
  • 临界质量 n* = (p − v)/k：线下是生死线，线上是补贴战的目的地
  • 双边市场定价非中性：补贴弹性大、网络贡献高的一侧，向依赖强的一侧收费
  • 赢家通吃需要强网络效应 + 低多归属 + 同质化；多归属与技术代际更替可打破
  • 免费不等于无势力：注意力与数据是隐性价格，免费侧的排他行为同样受反垄断审视
