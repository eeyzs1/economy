## 推荐学习路径

```
阶段一（地基）        阶段二（货币与国际）     阶段三（应用任选）         阶段四（视野）
01 微观 ──┬── 02 宏观 ── 05 货币 ──┐      09 劳动   12 环境资源    15 行为
          ├── 03 计量 ── 06 金融 ──┼── 10 产业   13 城市区域    16 政治经济与制度
          └── 04 博弈论 ─ 07 国际 ──┘      11 发展   14 健康教育   17 思想史（随时可读）
                                08 公共
```

- **零基础**：从 01 微观开始，它是一切的地图。
- **只想理解新闻**：01 → 02 → 05 → 07。
- **想做数据分析**：03 计量尽早学，配合 09/11/14 的实证案例。
- **随时可读**：17 思想史像"博物馆"，任何阶段进入都有收获。

## 每份教程的统一结构

每章按八段式设计（基于范例教学 + 检索练习的教学设计）：

1. **引入问题**——真实世界的好奇心钩子
2. **核心直觉**——类比与平实语言，先懂"为什么"再学"是什么"
3. **关键概念**——术语卡（中英对照）
4. **互动演示**——拖动滑块、点击按钮，亲手"玩"出结论
5. **现实世界**——中国与全球案例
6. **常见误区**——提前排雷
7. **自测**——选择题即时反馈，解析讲透"为什么"
8. **小结**——要点卡片

## 本地使用

- 所有页面为**纯静态 HTML**，无需服务器、可完全离线：双击 `index.html` 即可开始。
- 共享设计系统在 `assets/econ.css` 与 `assets/econ.js`，删除会导致样式与交互失效。
- 教材编写规范见 [DESIGN_SPEC.md](DESIGN_SPEC.md)（也用于继续扩展新分支）。
- **浏览器要求**：主题色等使用了 `color-mix()`（Chrome/Edge 111+、Safari 16.2+、Firefox 113+）。更旧的浏览器仍可阅读，但卡片底色、边框主题色与顶栏毛玻璃会降级为浅色/透明。

## 开发与质检

- 质检脚本：`node check.js <文件...>`（或一次传入全部页面）。它会检查：页面结构完整、quiz/术语卡/互动图数量下限、内联脚本语法、JS 引用的元素 id、label 与滑块/输出的对应、每个 SVG 的 aria-label、标题层级不跳级、pager 前后链接方向、主题色与规范一致、`curve-cN` 类在共享 CSS 中有定义（防"隐形曲线"）、跨文件链接目标存在、meta description 等。提交前请保证全部 PASS。
- 修改 `assets/` 下的共享 CSS/JS 后，建议用浏览器（无痕窗口）抽查 1~2 个分支页面的顶栏、目录高亮、测验反馈与移动端抽屉。
